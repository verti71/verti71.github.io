Privacy Policy — Pudła Panterki

Last updated: 12 November 2026 (12 listopada 2026). Operator: Pudła Panterki — prywatny projekt (pudla.nylon783@aleeas.com). PL: poniżej pełna polityka po angielsku; aplikacja jest prywatna, jednoosobowa i nie udostępnia danych nikomu.

1. What Google user data the app accesses

  • Gmail (scope gmail.readonly): only messages sent from the owner's own address that have PUDLA_BATCH or PUDLA_BRIDGE in the subject and carry attachments (Gmail search: from the owner's address, subject containing one of these words, with attachment). From those messages the app reads the subject, date, the plain-text body (which contains a box number and descriptions) and the image attachments; non-image attachments are ignored. Other messages are not requested by the app.
  • Google Photos (scopes photoslibrary.appendonly and photoslibrary.edit.appcreateddata): the app creates one album named "Pudła Panterki" and adds images and descriptions to it. It uses these permissions only to manage that album and the content it adds there, and does not use them for any other photos or albums.

2. How the data is used

Solely to provide the single feature described on the home page: uploading the owner's box photos with their descriptions to the album. Data is not used for advertising, profiling, analytics, machine-learning or model training, and is never sold.

3. Storage and retention

  • The Google authorization token (refresh token) is stored on a privately operated cloud server in the EU (Frankfurt) in a file readable only by the app's service account.
  • A small database on the same server keeps: the box number, file name, description, Google Photos item ID and link, upload status, and the IDs of processed e-mails. It contains no e-mail text other than the description supplied for the photo.
  • Image files received from e-mail are removed from the server after upload. Images submitted through the private web form may remain in a temporary queue folder on the server until the owner deletes them. The uploaded photos are stored in Google Photos.
  • Stored data (token, database, queue files) is kept until the owner deletes it. Revoking Google access stops the app from using Google data but does not by itself delete these server files or the photos in Google Photos; the owner deletes them manually.

4. Sharing

No Google user data is shared with, transferred to or disclosed to any third party, and no person other than the owner reads it. Data is processed only by the owner's own server and Google's APIs.

5. Security

Connections to Google APIs and to the web interface use HTTPS/TLS. Access to the web interface requires a secret access key; the server accepts remote logins only with SSH keys; secrets are kept out of public repositories.

6. Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions and may delete the stored token, the database, any remaining image files in the queue folder and the album. Questions or deletion requests: pudla.nylon783@aleeas.com.

7. Google API Services User Data Policy

Pudła Panterki's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes

Changes to this policy will be published on this page with an updated date.
